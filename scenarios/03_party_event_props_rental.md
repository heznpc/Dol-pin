# 시나리오 3: 파티/이벤트 소품 C2C 대여 플랫폼

> "생일 파티 소품, 한 번 쓰고 버릴 건가요?"

- 도메인: 파티 장식, 결혼식 소품, 졸업/돌잔치 데코레이션
- 모델: C2C 대여 마켓플레이스
- 블루오션 지수: ★★★★☆

---

## 1. 서비스 개요

생일 파티, 결혼식, 졸업식, 돌잔치, 베이비 샤워 등 일회성 이벤트에 필요한 장식/소품을 개인 간에 대여하는 C2C 플랫폼. 한 번 쓰고 버리거나 창고에 방치되는 파티 소품의 재활용 경제.

**원 라이너**: "파티 소품, 사지 말고 이웃에게 빌려라"

---

## 2. 시장 분석 (글로벌)

### 상위 시장

| 시장 | 규모 | 비고 |
|------|------|------|
| 글로벌 파티 용품 시장 | $132억 (2023) → $192억 (2030) | CAGR 5.5% |
| 글로벌 이벤트 장식 시장 | $78억+ (2024 추정) | 결혼식, 기업 이벤트 포함 |
| 미국 결혼식 평균 비용 | $35,000 (2024) | 장식이 전체의 8~10% |
| 글로벌 웨딩 시장 | $3,000억+ | 데코레이션이 핵심 지출 항목 |

### Pain Point의 수치적 근거

- 평균 생일 파티 장식 비용: $50~$200
- 평균 결혼식 데코 비용: $2,000~$5,000
- 사용 횟수: **1회** (그리고 영원히 창고/쓰레기통)
- 환경 이슈: 파티 용품 대부분 일회용 플라스틱. 지속가능성 트렌드와 충돌

### 지역별 특성

- **미국**: Pinterest/Instagram 중심 파티 문화 발달. DIY 데코 트렌드
- **한국**: 돌잔치, 백일, 생일 파티 문화 성장. SNS 인증 문화
- **유럽**: 지속가능성 의식 높음. 대여/재사용 수용도 높음
- **동남아**: 결혼식 문화 크지만 가격 민감. 대여 수요 잠재적

## 3. 타겟 유저

### 수요자

| 세그먼트 | Pain Point |
|----------|------------|
| 아이 생일 파티 부모 | 매년 다른 테마. 매번 $100+ 소품 구매 후 방치 |
| 결혼 예정 커플 | 아치, 센터피스, 조명 등 고가 소품 1회 사용 |
| 베이비 샤워/성별 공개 파티 | 인생 1~2번 이벤트에 $200+ 장식 구매 |
| 졸업 파티 | 풍선 아치, 배너, 포토존 소품 |
| 소규모 이벤트 기획자 | 전문 렌탈 업체보다 저렴한 소품 확보 |

### 공급자

| 세그먼트 | 동기 |
|----------|------|
| 파티 경험자 | 이미 구매한 소품이 창고에 방치 중. 수익화 가능 |
| DIY 파티 데코 제작자 | Etsy 판매 외 대여 수익 추가 |
| 결혼식 끝난 커플 | 아치, 조명, 테이블 세팅 등 재활용 희망 |
| 이벤트 소규모 업체 | 비수기 유휴 재고 수익화 |

## 4. Pain Point 검증

| Pain Point | 근거 | 강도 |
|------------|------|------|
| 1회 사용 후 폐기/방치 | 파티 소품의 90%+가 재사용 안 됨 | Strong |
| C2C 대여 플랫폼 부재 | 검색 결과 전부 B2C 렌탈 업체. C2C 전용 없음 | Strong |
| 높은 구매 비용 (결혼식/파티) | 결혼 데코 $2,000~$5,000, 생일 $50~$200 | Strong |
| 환경 지속가능성 요구 | 일회용 파티 용품에 대한 죄책감 증가 | Medium |
| 보관 공간 부족 | 대형 소품(아치, 배경막, 풍선 세트) 보관 어려움 | Medium |

## 6. 비즈니스 모델

### 수수료 구조

| 수익원 | 요율 | 설명 |
|--------|------|------|
| 거래 수수료 | 15~20% | 대여료 기준 |
| 배송 보조 서비스 | 건별 | 대형 소품 픽업/배송 연계 |
| 파티 패키지 추천 | 커미션 | 테마별 소품 세트 큐레이션 |

### 수익 시뮬레이션

파티 소품 평균 대여가: $15~$50/세트 (결혼 소품은 $100~$300)
보증금: 물품 가치의 50%

**Phase 1 (미국, 1년 후)**: 월 800건 x $40 x 17.5% = $5,600/월
**Phase 2 (미국+유럽, 2년 후)**: 월 5,000건 x $50 x 17.5% = $43,750/월

### 확장 로드맵

1. 생일 파티 소품 C2C 대여 (MVP)
2. 결혼식/베이비 샤워 소품 확장
3. 파티 플래너/데코 서비스 연계
4. 이벤트 용품 B2B 렌탈 통합
5. 지속가능 파티 브랜드로 포지셔닝

## 7. 핵심 리스크

| 리스크 | 심각도 | 대응 |
|--------|--------|------|
| **물류 복잡성** (대형 소품 운송) | 높음 | 지역 기반 매칭 우선, 직거래 유도. 대형 소품은 픽업 서비스 연계 |
| **낮은 객단가** (소품 단품) | 중간 | 세트/패키지 대여 유도. "공주 테마 파티 풀세트" 등 |
| **소품 상태 관리** | 중간 | 사진 필수, 상태 등급 시스템 |
| **시즌성** (결혼/졸업 시즌 집중) | 중간 | 생일은 연중 분산, 크리스마스/할로윈 등 추가 시즌 |
| **위생** (풍선, 식기류 등) | 낮음 | 소모성 아이템(풍선 등) 제외, 재사용 가능 소품만 |

## 8. 종합 평가

| 항목 | 점수 | 비고 |
|------|------|------|
| 블루오션 (경쟁 공백) | ★★★★☆ | B2C만 존재, C2C 전용 없음 |
| 수요 검증 | ★★★☆☆ | 간접적 (1회 사용 폐기 문화). 직접 대여 거래 데이터 부족 |
| 바이럴 잠재력 | ★★★☆☆ | Pinterest/인스타 파티 문화와 연결 가능하나, 팬덤만큼 강하지 않음 |
| 객단가 | ★★★☆☆ | 파티 소품 낮음, 결혼 소품은 높음 |
| 거래 빈도 | ★★★☆☆ | 생일은 연중 분산. 결혼/졸업은 시즌 |
| 닭-달걀 난이도 | ★★★☆☆ | "이미 쓴 파티 소품"이 많아 공급 확보 비교적 쉬움 |
| 1인 개발 적합도 | ★★★☆☆ | 물류 복잡도가 높아 운영 부담 |
| 글로벌 확장성 | ★★★★☆ | 파티 문화는 글로벌, 특히 미국/유럽 |

**총평**: "한 번 쓰고 버리는 파티 소품"이라는 pain point는 명확하고 공감대가 넓다. 지속가능성 트렌드와도 잘 맞는다. 하지만 대형 소품 물류와 낮은 단가가 과제. 결혼식 소품(고단가)을 킬러 카테고리로 잡고, 생일 파티(빈도)로 보완하는 투 트랙 전략이 유효. 팬덤 같은 강한 커뮤니티 바이럴이 없어 초기 성장이 느릴 수 있음.
