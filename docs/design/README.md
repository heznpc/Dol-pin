# Mobile reference

`mobile-reference.png`는 기존 Flutter의 어두운 배경과 보라색 강조색을 기준으로
만든 생성형 디자인 참고 이미지다. 완성 화면이나 구현 증거가 아니다.

실제 화면에는 backend의 데이터만 표시한다. 참고 이미지의 예시 일정, 즐겨찾기,
거래 상태는 구현 요구사항으로 승계하지 않는다. 카테고리는 기존 콘서트 물품
범위로 유지한다. UI 문구와 입력 요소는 native component로 구현한다.

`assets/demo/lightstick.png`는 브랜드 없는 합성 제품 사진이다. 로컬 demo fixture에만
사용하며 실제 등록 상품이나 거래 실적으로 표현하지 않는다.
