# dol-pin 60~90초 시연 영상 대본

목표 길이: 75초 내외

주의: 실제 영상에서 Bluetooth 현장 검증, 자동 반납 사진 판정, 자동 대여자 정산을 완료 기능처럼 보여주지 않습니다. 결제/Gemini 실환경 증빙이 없으면 해당 장면은 "프로토타입 구조" 또는 "시연용 sandbox"로 표시합니다.

## 화면 순서 요약

1. 콘서트 선택
2. 물품 등록
3. AI 사진 검증
4. 예약
5. 결제/상태 전환
6. 반납/분쟁 흐름

## 화면별 촬영 체크리스트

| 화면 | 꼭 보여줄 것 | 없으면 대체 |
|---|---|---|
| 콘서트 선택 | 콘서트 카드, 탐색 이동 | 테스트 데이터가 없으면 mock/staging 데이터 준비 후 촬영 |
| 물품 등록 | 사진 2장 이상, 콘서트, 가격, 보증금, 픽업 장소 | 입력 폼만 촬영하고 저장 성공은 별도 로그로 보강 |
| AI 사진 검증 | `autoTagging` 진행 표시 또는 AI 태그 결과 | 실제 Gemini 키가 없으면 코드/구조 검증 장면으로 낮춰 설명 |
| 예약 | 날짜 선택, 총액, 보증금, SafeBadge | 결제 전 요약 화면만으로도 아이디어 트랙에는 충분 |
| 결제/상태 전환 | PortOne sandbox 또는 예약 상세 `paid` 상태 | sandbox가 없으면 실결제 미검증이라고 명시 |
| 반납/분쟁 | 반납 사진 촬영, `returned` 또는 `disputed` 흐름 | 실제 카메라 권한/스토리지 없으면 reservation detail UI와 코드 증빙으로 보강 |

## 제출 영상 자막 문구

짧은 자막:

> 콘서트 기반 물품 대여
> AI 사진 분석으로 등록 보조
> 예약/결제/반납 상태 기록
> 반납 사진과 분쟁 처리로 신뢰 강화
> 외국인 팬과 초행 관람객까지 고려한 다국어 UI
