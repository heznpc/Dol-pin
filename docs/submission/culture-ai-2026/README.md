## 서비스 요약

**서비스명:** dol-pin

**한 줄 설명:** K-pop 콘서트 현장에서 팬들이 응원봉, 배터리, 촬영/응원 용품 등을 더 안전하게 빌리고 돌려줄 수 있도록 돕는 AI 기반 콘서트 물품 대여 플랫폼.

dol-pin은 콘서트 단위로 대여 물품을 탐색하고, 물품 등록 시 사진을 AI로 분석해 태그와 카테고리를 보조하며, 예약/결제/픽업/반납/분쟁 상태를 기록하는 모바일 앱 프로토타입입니다.

## 문제 정의

콘서트 현장의 팬 간 물품 대여는 빠르고 유연하지만 신뢰 비용이 큽니다.

| 문제 | 현장 영향 |
|---|---|
| 사기와 계정 신뢰 부족 | DM 기반 거래에서 물품 실재 여부와 판매자 신뢰 확인이 어렵습니다. |
| 보증금 분쟁 | 반납 여부, 파손 여부, 환불 기준이 대화 캡처에 의존하기 쉽습니다. |
| 물품 상태 확인 | 등록 사진과 실제 반납 상태가 흩어져 있어 분쟁 시 증거가 약합니다. |
| 언어 장벽 | 외국인 팬과 초행 관람객은 대여 조건, 픽업 장소, 반납 절차를 이해하기 어렵습니다. |
| 현장 반납 증빙 | 공연 종료 후 혼잡한 이동 상황에서 반납 기록이 누락되기 쉽습니다. |

## AI 활용

핵심 AI 기능은 **Gemini 기반 물품 사진 분석/검증 보조 흐름**입니다.

앱은 등록된 물품 사진을 Supabase Edge Function으로 보내고, Edge Function은 Gemini API를 호출해 물품 유형, 아티스트/브랜드 단서, 모델/색상/상태를 짧은 태그로 반환하도록 설계되어 있습니다. 이 결과는 물품 등록 과정에서 카테고리와 설명 보조 정보로 활용됩니다.

현재 AI는 자동 승인/자동 판정자가 아닙니다. 자동 반납 사진 판정, 자동 손상 판정, Bluetooth 정품 인증은 제출 문서에서 완료 기능으로 쓰지 않고 로드맵으로만 다룹니다.

## 시연 플로우

제출 영상은 아래 순서로 구성합니다.

1. 콘서트 선택: 홈에서 공연을 선택하고 해당 공연 물품 목록으로 이동합니다.
2. 물품 등록: 응원봉/배터리/촬영 보조 물품 사진을 추가하고 기본 정보를 입력합니다.
3. AI 사진 검증: Gemini 태그/카테고리 제안이 표시되는 장면을 보여줍니다.
4. 예약: 대여 날짜와 보증금 포함 금액을 확인합니다.
5. 결제/상태 전환: KRW 결제 검증 구조와 예약 상태 변경 설계를 설명합니다.
6. 반납/분쟁: 반납 사진 업로드, 보증금 정산, 분쟁 접수/운영자 해결 흐름을 보여줍니다.

상세 대본은 `demo-script.md`에 있습니다.
