# dol-pin 공모전 기획서 초안

## 서비스 개요

dol-pin은 K-pop 콘서트 현장에서 팬들이 응원봉, 배터리, 촬영/응원 용품 등을 더 안전하게 빌리고 돌려줄 수 있도록 돕는 AI 기반 콘서트 물품 대여 플랫폼입니다.

콘서트 현장 대여는 빠르지만 신뢰 비용이 큽니다. 물품 사진, 보증금, 픽업/반납 상태, 결제 검증, 분쟁 증빙이 서로 분리되어 있으면 팬들은 사기나 보증금 분쟁에 노출됩니다. dol-pin은 콘서트 기반 탐색, AI 사진 분석, 예약/보증금/반납 상태머신, 반납 사진, 분쟁 처리 흐름, 다국어 UI를 한 흐름으로 묶어 더 안전한 공연 경험을 제안합니다.

## 기획성

K-pop 공연은 같은 장소와 시간에 많은 팬이 모이는 문화 활동입니다. 응원봉, 보조배터리, 촬영 보조 장비, 슬로건, 의상 소품 등은 공연 당일 수요가 집중되지만, 모두가 매번 새 물품을 구매하기는 어렵습니다.

현재 팬 간 대여는 DM, 중고거래 게시글, 수작업 대여 계정 등에 의존하는 사례가 있을 수 있습니다. 이 방식은 접근성이 높지만 거래 기록이 흩어지고, 물품 상태와 반납 증빙이 명확하지 않으며, 외국인 팬과 초행 관람객이 조건을 이해하기 어렵습니다.

dol-pin은 이 문제를 다음 흐름으로 해결하도록 설계되었습니다.

| 단계 | 설계 |
|---|---|
| 탐색 | 콘서트 기준으로 대여 가능한 물품을 찾습니다. |
| 등록 | 물품 사진, 가격, 보증금, 픽업 위치, 가능 기간을 구조화합니다. |
| AI 보조 | Gemini 기반 사진 분석으로 물품 태그와 카테고리 입력을 보조합니다. |
| 예약 | 서버가 물품 정보와 기간을 기준으로 예약 의도를 생성합니다. |
| 결제 검증 | PortOne 결제 후 Edge Function이 결제 ID, 금액, 통화를 검증합니다. |
| 반납/분쟁 | 반납 사진과 상태 전환을 남기고, 분쟁은 운영자 해결 흐름으로 분리합니다. |

## 적합성

본 서비스는 문화 분야 중 K-pop 공연 관람 현장의 실질 문제를 다룹니다. 공연 경험은 티켓 구매나 공연장 입장만으로 끝나지 않고, 응원 문화, 팬덤 물품, 현장 이동, 팬 간 상호작용으로 확장됩니다.

dol-pin은 AI와 디지털 기술을 사용해 공연 현장 물품 대여의 신뢰 문제를 줄이는 서비스입니다. 따라서 신기술활용 ADX 아이디어 트랙의 "AI·디지털 기술을 활용한 문화서비스 사각해소 및 국민체감형 서비스 기획" 취지에 맞습니다.

또한 다국어 UI를 통해 외국인 팬, 초행 관람객, 청소년/대학생 팬 등 기존 DM 거래에서 정보 비대칭이 큰 사용자를 고려합니다.

## 차별성

dol-pin의 차별점은 단순 물품 목록이 아니라 **콘서트 현장 신뢰 흐름**을 제품 구조로 다루는 점입니다.

| 기존 방식의 한계 | dol-pin의 차별화 방향 |
|---|---|
| DM 거래는 물품 상태/보증금/반납 증빙이 흩어짐 | 사진, 예약, 결제, 반납 상태를 하나의 예약 기록으로 묶음 |
| 일반 중고거래 앱은 공연 당일 대여 맥락이 약함 | 콘서트 기준 탐색과 날짜 기반 예약 흐름 제공 |
| 물품 설명은 판매자 수기 입력에 의존 | Gemini 사진 분석으로 태그와 카테고리 입력 보조 |
| 분쟁 발생 시 증거가 대화 캡처에 치우침 | 반납 사진과 상태머신으로 최소 증빙 경로 제공 |
| 외국인 팬은 조건 이해가 어려움 | KO/EN/JA/ID 다국어 UI 기반 제공 |

Bluetooth 현장 검증, 자동 반납 사진 판정, 자동 대여자 정산은 현재 완료 기능이 아니라 Phase 2 로드맵입니다. 제출 문서에서는 현재 구현된 AI 사진 분석/상태 기록 중심으로 범위를 제한합니다.

## 활용성

dol-pin은 공연 당일과 전후 하루 단위의 짧은 대여 상황에 맞춘 모바일 흐름을 제공합니다.

사용자는 공연을 선택한 뒤 대여 가능한 물품을 확인하고, 날짜와 보증금 포함 총액을 확인할 수 있습니다. 대여자는 물품 사진과 픽업 장소를 등록하고, AI 태그 보조를 통해 등록 부담을 줄일 수 있습니다. 반납 시에는 사진을 남겨 사후 분쟁 가능성을 낮춥니다.

현재 레포 기준으로 Flutter 앱, Supabase 기반 데이터 구조, Edge Function, 결제 검증 구조, 상태머신, 다국어 UI, 로컬 검증 스크립트가 포함되어 있습니다. 제출 전 실제 영상 촬영이 가능하도록 60~90초 시연 대본도 준비했습니다.

## 사회적 기여도

dol-pin은 공연 문화에 참여하는 팬들의 안전과 접근성을 높이는 것을 목표로 합니다.

| 대상 | 기대 효과 |
|---|---|
| 외국인 팬 | 언어 장벽과 현장 거래 불안을 줄이고, 공연 경험 접근성을 높입니다. |
| 초행 관람객 | 픽업/반납/보증금 흐름을 앱 안에서 확인해 현장 혼란을 줄입니다. |
| 청소년/대학생 팬 | 고가 물품을 매번 구매하지 않고 필요한 기간에 빌릴 수 있습니다. |
| 대여자 | 수작업 DM 관리 부담을 줄이고 분쟁 대응에 필요한 기록을 남깁니다. |
| 공연 생태계 | 팬덤 물품 재사용을 촉진하고 공연장 주변 비공식 거래의 위험을 낮춥니다. |

본 서비스는 특정 팬덤이나 특정 공연장에 한정하지 않고, 공연 문화 전반의 안전한 참여 경험을 위한 디지털 신뢰 인프라를 지향합니다.

## AI 활용성

dol-pin의 AI 활용은 물품 등록 단계의 사진 분석에서 시작합니다.

사용자가 물품 사진을 등록하면 앱은 Supabase Edge Function을 통해 Gemini에 이미지를 전달합니다. Gemini는 물품 유형, 아티스트/브랜드 단서, 모델/색상/상태를 분석해 짧은 태그를 반환하고, 앱은 이를 카테고리와 설명 입력 보조에 활용합니다.

AI 활용의 목적은 다음과 같습니다.

| 목적 | 설명 |
|---|---|
| 등록 부담 감소 | 사용자가 긴 설명을 직접 쓰지 않아도 기본 태그를 생성합니다. |
| 물품 식별 보조 | 응원봉, 배터리, 카메라, 슬로건 등 카테고리 분류를 보조합니다. |
| 거래 신뢰 향상 | 등록 사진 기반 설명을 남겨 물품 상태 확인의 출발점을 만듭니다. |
| 확장 가능성 | 향후 반납 사진 비교, 손상 징후 탐지, Bluetooth 현장 검증과 결합할 수 있습니다. |

현재 AI는 자동 승인/자동 반납 판정자가 아닙니다. 사람이 확인 가능한 태그와 증빙 흐름을 보조하는 역할로 제한합니다. 이 제한은 과장 방지와 분쟁 책임 경계를 명확히 하기 위한 설계입니다.
